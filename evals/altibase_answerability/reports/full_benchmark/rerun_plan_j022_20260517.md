## Full Live Run

Use a new run id and keep large outputs under the ignored `runs/` directory:

```bash
RUN_ID="altibase_answerability_$(date -u +%Y%m%d_%H%M%S)"
ARTIFACTS="evals/altibase_answerability/reports/full_benchmark/runs/${RUN_ID}"
mkdir -p "${ARTIFACTS}/answers" "${ARTIFACTS}/judge"

{
  printf 'Altibase answerability test\n'
  printf 'run_id=%s\n' "${RUN_ID}"
  printf 'mode=live provider=command model=codex-exec context=lexical\n'
  printf 'provider_command=evals/altibase_answerability/scripts/codex_exec_provider.sh\n'
  printf 'artifacts=%s\n' "${ARTIFACTS}"

  python3 evals/altibase_answerability/scripts/validate_benchmark.py \
    --manifest evals/altibase_answerability/manifests/full_benchmark.json

  python3 evals/altibase_answerability/scripts/answer_runner.py --self-test
  python3 evals/altibase_answerability/scripts/judge_report.py --self-test

  python3 evals/altibase_answerability/scripts/answer_runner.py \
    --manifest evals/altibase_answerability/manifests/full_benchmark.json \
    --run-id "${RUN_ID}" \
    --mode live \
    --provider command \
    --model codex-exec \
    --provider-command evals/altibase_answerability/scripts/codex_exec_provider.sh \
    --context-mode lexical \
    --validate-output \
    --output-dir "${ARTIFACTS}/answers"

  python3 evals/altibase_answerability/scripts/judge_report.py \
    --manifest evals/altibase_answerability/manifests/full_benchmark.json \
    --policy evals/altibase_answerability/policy.json \
    --answers "${ARTIFACTS}/answers/answers.jsonl" \
    --validate-output \
    --output-dir "${ARTIFACTS}/judge"

  python3 - "${ARTIFACTS}" <<'PY'
import json
import sys
from pathlib import Path

artifacts = Path(sys.argv[1])
aggregate = json.loads((artifacts / "judge" / "aggregate_report.json").read_text())
metrics = aggregate["overall_metrics"]
summary = "\n".join([
    "Altibase answerability test summary",
    f"Run ID: {aggregate['run_id']}",
    f"Decision: {aggregate['readiness_decision']}",
    f"Totals: {aggregate['totals']['passed']}/{aggregate['totals']['questions']} passed, {aggregate['totals']['failed']} failed",
    f"Pass rate: {metrics['pass_rate'] * 100:.1f}%",
    f"Critical fact coverage: {metrics['critical_fact_coverage'] * 100:.1f}%",
    f"Required token preservation: {metrics['required_token_preservation'] * 100:.1f}%",
    f"Unsupported-claim rate: {metrics['unsupported_claim_rate'] * 100:.1f}%",
    f"Protected-topic blockers: {sum(item['count'] for item in aggregate['protected_topic_blockers'])}",
    f"Report: {artifacts / 'judge' / 'report.md'}",
    f"Aggregate JSON: {artifacts / 'judge' / 'aggregate_report.json'}",
    f"Answers: {artifacts / 'answers' / 'answers.jsonl'}",
    f"Judgments: {artifacts / 'judge' / 'judgments.jsonl'}",
])
(artifacts / "summary.txt").write_text(summary + "\n")
print(summary)
PY
} | tee "${ARTIFACTS}/run-test.log"
```

## Result Review Order

Open these files first:

1. `${ARTIFACTS}/summary.txt`
2. `${ARTIFACTS}/judge/report.md`
3. `${ARTIFACTS}/judge/aggregate_report.json`
4. `${ARTIFACTS}/judge/judgments.jsonl`
5. `${ARTIFACTS}/answers/answers.jsonl`

If the decision is not a pass, triage in this order:

1. Protected-topic blockers.
2. Domain pass rates below 80.0%.
3. Critical fact coverage misses.
4. Required token preservation misses.
5. Unsupported claims.
6. Version-handling and missing-input-handling regressions.

Classify each sampled failure as one of:

- `content gap`: the source-backed item or exact token is absent from the attachment
  set;
- `retrieval gap`: the item exists in full attachments but was not selected in lexical
  context;
- `answer synthesis gap`: the item was selected but the answer omitted, weakened, or
  paraphrased it;
- `judge calibration issue`: only after source, selected context, full context, and
  answer path have been checked.
