- Workflow: `altibase-gpt-full-coverage-audit`

## Register Contract

Add one entry for every source-backed, in-scope item that is not answerable from
`GPTs/attachments/`. Remove, close, or supersede the entry only when the corresponding
catalog and matrix rows no longer have unresolved `Missing` status.

Each entry should record:

- `source_item_id`
- source family and version scope
- source path and heading
- missing answer-ready fields
- affected attachment target
- required remediation shape
- audit job and evidence
