## Specific Scope

Create the Stage 2 playbook directory, source-routing plan, manifest schema, and
validation scaffolding before domain playbooks are drafted.

Expected outputs:

- `GPTs/agent_playbooks/README.md`
- `GPTs/agent_playbooks/playbook_manifest.tsv`
- `GPTs/agent_playbooks/scripts/validate_playbooks.py`
- updates to `GPTs/reports/stage_02_agent_playbooks_plan.md`

The manifest schema must support, at minimum:

- playbook ID;
- path;
- title;
- domain;
- supported versions;
- source IDs;
- source-pack block IDs;
- Korean-aligned baseline block IDs;
- AID route or tier when used;
- generated artifact types;
- protected-topic flag;
- required missing-input prompts;
- validation status;
- owning Stage 2 job.

The validation script should be deterministic and should initially validate schema,
file existence, duplicate IDs, source-ID format, baseline/source-pack reference
format, required domain coverage placeholders, and forbidden upload-package or
attachment edits.
