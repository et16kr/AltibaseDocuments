# Job S1-J012: Stage 1 integration cross-check

## Goal

Check source-pack to baseline coverage, AID tier coverage, downstream routing readiness,
and remaining not-ready gaps before final readiness review.

## Scope

- Work only on this job.
- Read the existing project instructions before editing.
- Use repository-relative paths; `run-all.sh` invokes Codex from the repository root.
- Do not revert unrelated user changes.
- Before editing, stop if there are uncommitted project files outside `.codex-jobs/`.
- Complete the scoped job without asking for step-by-step confirmation unless blocked
  or unsafe.

## Required Steps

1. Reconfirm the job requirement and boundary.
2. Inspect source-pack, baseline, AID, and conflict validation artifacts.
3. Build or update integration cross-check evidence.
4. Record missing coverage, weak routing, or downstream blockers.
5. Self-review for stale source IDs, missing AID rows, and overbroad ready claims.
6. Apply fixes from the review.
7. Run the required checks.
8. Review the final diff.
9. Commit the completed job with a focused message. Do not report success without a
   commit.

## Acceptance Criteria

- The goal above is complete or explicitly blocked with source IDs and reasons.
- Relevant checks have passed or skipped checks are explicitly explained.
- The final review passed.
- The job result is committed, and project files are clean after the commit.
