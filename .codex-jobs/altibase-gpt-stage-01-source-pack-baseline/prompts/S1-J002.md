## Specific Scope

Inventory selected repository-local source files and approved support evidence.

Expected outputs:

- `GPTs/source_pack/source_manifest.tsv`
- `GPTs/source_pack/source_exclusion_register.tsv`
- `GPTs/source_pack/scripts/build_source_manifest.py` or an equivalent deterministic
  recorded command/script

The source manifest must record at least:

- source ID
- source path
- source family
- version scope
- language
- authority label
- include/exclude disposition
- exclusion or limitation reason when excluded
- checksum
- byte count
- line count
- estimated token count

Repository-local source roots to consider:

- `Manuals/`
- `ReleaseNotes/`
- `PatchNotes/`
- `Technical Documents/`
- `3rd Party Guide for Altibase/`

Support reports under `GPTs/reports/` may be included only when the job records why the
report is approved support evidence. Requirements, readiness drafts, transient review
notes, and generated validation logs are not product sources by default.

- Check for duplicate source IDs.
- Check that every included source path exists.
- Check that every excluded candidate has a reason.
- Run `git diff --check -- GPTs/source_pack`.
