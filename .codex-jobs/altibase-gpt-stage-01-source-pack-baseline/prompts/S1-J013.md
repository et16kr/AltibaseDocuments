# Job S1-J013: Stage 1 readiness review

## Goal

Run Stage 1 validation, review all source-pack and baseline deliverables, write
readiness or not-ready report, and commit final Stage 1 readiness evidence.

## Scope

- Work only on this job.
- Read the existing project instructions before editing.
- Use repository-relative paths; `run-all.sh` invokes Codex from the repository root.
- Do not revert unrelated user changes.
- Before editing, stop if there are uncommitted project files outside `.codex-jobs/`.
- Complete the scoped job without asking for step-by-step confirmation unless blocked
  or unsafe.

## Required Steps

1. Reconfirm the job requirement and boundary.
2. Inspect all Stage 1 deliverables and validation artifacts.
3. Run or rerun final Stage 1 validation commands.
4. Write the readiness or not-ready report without weakening gates.
5. Self-review for unsupported ready claims, missing blockers, and stale evidence.
6. Apply fixes from the review.
7. Run the required checks.
8. Review the final diff.
9. Commit the completed job with a focused message. Do not report success without a
   commit.

## Acceptance Criteria

- The readiness report states `Ready for Stage 2` only if all Stage 1 gates pass.
- If any gate fails, the readiness report states `Not ready for Stage 2` and records
  blockers.
- Relevant checks have passed or skipped checks are explicitly explained.
- The job result is committed, and project files are clean after the commit.

## Required Checks

Run available checks, at minimum:


If validation scripts exist, run them. If they cannot run, explain why in the readiness
report and mark Stage 1 not ready when the missing check affects a required gate.
