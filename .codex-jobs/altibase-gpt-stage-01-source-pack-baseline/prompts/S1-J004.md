## Specific Scope

Implement or update deterministic source-pack generation and generate the source pack.

Expected outputs:

- `GPTs/source_pack/scripts/build_source_pack.py` or equivalent deterministic script
- `GPTs/source_pack/*.md` source-pack shard files
- `GPTs/source_pack/source_to_shard_manifest.tsv`

Source-pack shards must:

- include selected source Markdown exactly once, unless excluded with reason;
- preserve original content inside stable source boundary markers;
- record source ID, path, family, version scope, language, authority, checksum, byte
  count, line count, and estimated token count;
- keep source-pack files as evidence artifacts unless later selected or transformed into
  `GPTs/upload_package/`.

## Required Checks

- Run the source-pack generation script.
- Check that every included manifest row appears in exactly one shard.
- Check that each shard has source boundary markers.
- Run `git diff --check -- GPTs/source_pack`.
