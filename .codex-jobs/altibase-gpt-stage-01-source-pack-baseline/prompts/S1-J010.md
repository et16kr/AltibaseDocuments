# Job S1-J010: Release patch technical AID baseline batch

## Goal

Generate or reuse Korean-aligned English baseline blocks for release notes, patch notes,
technical documents, third-party guides, and AID upload candidates, or record scoped
not-ready gaps.

## Scope

- Work only on this job.
- Read the existing project instructions before editing.
- Use repository-relative paths; `run-all.sh` invokes Codex from the repository root.
- Do not revert unrelated user changes.
- Before editing, stop if there are uncommitted project files outside `.codex-jobs/`.
- Complete the scoped job without asking for step-by-step confirmation unless blocked
  or unsafe.

## Required Steps

1. Reconfirm the job requirement and boundary.
2. Inspect the relevant manifests, AID tier manifest, source-pack validation, and
   baseline manifest.
3. Generate, reuse, or update only the scoped baseline files and manifest rows.
4. Preserve AID classifications and record conflicts, limitations, recheck items, and
   not-ready gaps.
5. Self-review for patch/version boundaries, AID classification preservation, and
   unsupported inference.
6. Apply fixes from the review.
7. Run the required checks.
8. Review the final diff.
9. Commit the completed job with a focused message. Do not report success without a
   commit.

## Acceptance Criteria

- The goal above is complete or explicitly blocked with source IDs and reasons.
- Relevant checks have passed or skipped checks are explicitly explained.
- The final review passed.
- The job result is committed, and project files are clean after the commit.

## Specific Scope

Generate or reuse Korean-aligned English baseline blocks for source groups covering:

- release notes and exact version boundaries;
- 7.1 and 7.3 patch notes, patch-specific behavior, `BUG-*`, and `TASK-*` tokens;
- selected technical documents and third-party guides;
- AID upload-content candidates, including stabilized English and source-backed
  `~/AID/llm-reference/` files when evidence supports use.

For AID:

- reuse Korean-source-updated English content when its evidence classification permits;
- preserve `Korean-source-verified`, `link-validated Korean-source-verified`,
  `English-only source`, and `source_limitation` classifications;
- keep evidence-only authority files outside customer upload content by default.

Expected outputs:

- one or more `GPTs/korean_aligned_english/*.md` files for this batch;
- updates to `GPTs/korean_aligned_english/baseline_manifest.tsv`;
- updates to `GPTs/reports/source_conflict_register.md`;
- updates to `GPTs/reports/aid_tier_manifest.tsv` only when a justified classification
  correction is discovered.

If this batch is still too large, complete a deterministic manifest-recorded subset and
write exact remaining source IDs as not-ready gaps.
